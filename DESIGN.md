# SOPEasy visual system

## Direction
Process atlas. A calm editorial document workspace with visual process notation. Warm light canvas, near-black ink, desaturated green and clay highlights. A persistent narrow navigation rail and a generous reading field; user tasks, editorial headings and a crisp process diagram lead the home page.

The assigned grounded direction from concept seed 310d8370 was candidate 6, process notation and analytical graphics. Boarding-board clarity contributes persistent change status. Reference-manual hierarchy contributes a stable document outline. Atlas notation contributes relationships rather than ornamental illustrations. Data-strobe and constructed-letter challengers are declined because HR users need sustained comfortable reading. No strobing.

## Type and tokens
Self-hosted Geist for controls and body. Instrument Serif for the distinctive home heading and large display moments. Ink #242820, secondary #59684e, muted #626d56, canvas #f7f7f2, paper #fffefb, line #e5e7de, green #4c6441, sage #e7ecdf, clay #b86e4a, pale clay #f4e7dd. Body 14px/1.5; display 56px/1.05; document text 13px on desktop and 14px on mobile with generous line spacing. Tracking no tighter than -0.035em. Clay text uses #785135 and blue text uses #496277 to retain contrast on pale surfaces.

## Interaction
One authored document-to-review-to-publication diagram with moving signal dots. Page transitions use a small spatial reveal, button presses compress by 2%, status changes preserve identity. No unearned decorative gradient, invented activity graph, or meaningless score. Reduced motion removes movement. Geometry in SVG remains crisp; it never imitates a hand-drawn picture.

## Composition
Sidebar 236px desktop; content maximum 1440px. The document outline, editor, and workflow inspector occupy distinct columns. Source notes and workflow tabs move below the document on small screens. Spacious list rows with deliberate metadata. Radius 10–14px containers and 7px controls. Borders define structure; no nested decorative cards. The quiet brand layer yields to task state. The library offers category, department, process owner, and maintenance filters with server pagination; the search dialog and review queue use bounded pages as well.

## Quality
Responsive down to 360px. Real labels and actions, keyboard focus, error recovery, accessible dialog focus and dismissal, busy states, semantic headings, permission-aware actions. Demonstration data is identified. All workflow controls perform real server writes.

The mechanical Impeccable detector reported Geist as an overused font. It remains intentionally as a quiet control face paired with Instrument Serif; the distinctive composition and authored process graphic carry the brand. Secondary text uses #59684e after contrast inspection. Source notes remain below the editor on small screens; no text disappears into an offscreen inspector. Mobile navigation makes background controls inert and keeps keyboard focus inside. Native dialogs cycle focus and restore the initiating control on dismissal. Older AI proposals retain a preview but disable replacement after the working revision changes. Accessibility scans wait for finite entrance animations to settle, so transient fades do not count as the resting text contrast.
