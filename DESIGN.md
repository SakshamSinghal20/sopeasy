# SOPEasy visual system

## Direction
A calm procedure workspace. White reading surfaces, a silver workspace canvas, charcoal text and restrained pastel states keep attention on the current task. Preserve the authored procedure-to-review-to-publication diagram and the simple document lifecycle.

## Typography
Self-host Inter 400, 400 italic, 500, 600 and 700 for body text, controls and author-written emphasis. Use Space Grotesk 600 and 700 for headings, the product wordmark and procedure titles. Text remains visible during font loading. Display headings use a restrained scale and tracking no tighter than -0.035em. Mobile home headings use 34–44px; mobile procedure titles use 30–32px. Body text remains 14px with generous line spacing; document text remains 13px on desktop and 14px on mobile. Keep author-written emphasis in Inter italic.

## Palette and roles
- Ink #111111: primary text, icons, buttons and focus rings.
- White #FFFFFF: document, dialog and sidebar surfaces.
- Soft white #F8F9FA: workspace canvas and quiet hover regions.
- Silver #EBEDF0: separators, chips, neutral states and grouped controls.
- Muted #4B5563: supporting text and metadata.
- Mint #86DEB4: selected navigation, approvals and the review stage in the diagram.
- Sky #82C3FF: review/generation states and the publication stage in the diagram.
- Gold #F0D679: attention-required states, paired with a written status label.
- Rose #F49AB1: an existing avatar variant; error controls use a contrast-safe dark rose #9A2538.
- Lilac #C0A1EE: available brand token, reserved for a future distinct category.

Use Ink text on pastel fills. Primary actions use white text on Ink. Control borders use #858B95 to remain visible against white. The palette describes state through text, icons and position as well as color. Keep accent use limited to existing labeled states; avoid decorative gradients.

## Navigation and composition
Keep four main destinations visible: Home, Procedures, My tasks and Reviews. Group secondary destinations in the existing More disclosure. Preserve the current section outline, back navigation, search, draft preview and workflow inspector. Add no navigation layers or new controls as part of branding.

The desktop sidebar remains 236px, with a generous main reading field. On mobile, the navigation drawer supports keyboard focus and closes after destination selection. The existing single-column document layout places notes and workflow controls below the editor. Container and control geometry remains consistent with the current interface.

## Interaction and quality
Keep the authored diagram's signal motion, tactile buttons and small page reveals. Reduced motion removes movement. Preserve real workflow actions, permission-aware controls, accessible dialog focus, visible errors and labeled sample data. Inspect desktop and mobile in one pass, fix observed issues together and confirm once. Browser selection, caret, scrollbars, focus and numeric metadata use the shared tokens.
